# Textures, packs and references.

Assets

The libraries worth bookmarking, and a gallery of stud-style builds to study before you place a single part.

## VFX texture pack

1,936 effect textures for Roblox particles, beams and trails, split into three downloads so you only grab what you need. Resize to 1024 px or less before uploading; textures on a black background are for additive glow layers (LightEmission 1). See the [[VFX particles, layering and colour|VFX guides]] for how to layer them.

Free to download. Hosting nearly half a gigabyte isn't, so if the pack helps, [you can chip in](https://roclicks.gg/support).

## Libraries

- UI
  ### UI Resources

  Free textures and effects for game UI: the stud texture for stud-style panels, glows, gradients, frames and backgrounds.

  Tip: Some files named .png are really WebP. Check the real file type and convert to PNG before uploading, because Roblox only accepts PNG, JPG, BMP and TGA.

  [Open UI Resources↗](https://ui-resources.com)

- 3D
  ### Poly Haven

  Free CC0 textures, HDRIs and 3D models, usable in any project with no credit required.

  Tip: Great for realistic surfaces in the Cinematic style and for lighting reference renders in Blender.

  [Open Poly Haven↗](https://polyhaven.com)

- Tool
  ### VFX Forge

  A Roblox VFX editor plugin. Its EmitCount, EmitDelay and EmitDuration attributes are the convention the VFX guides on this site use.

  [Open VFX Forge↗](https://docs.zilibobi.dev/vfx-forge/effects/particle/)

Then the import prompt turns that page into a real Roblox ScreenGui.[[The HTML UI prompt recreate a UI from a screenshot|The HTML UI prompt]][[The UI import prompt HTML to a Roblox ScreenGui|The import prompt]]

## Tools

What the guides and prompts on this site are actually made with.

### Thumbnails

- [Google Flow↗](https://flow.google.com)

  The best thumbnail results so far: Nano Banana Pro with 4 to 10 reference thumbnails attached, ten ideas per batch.

### 3D models

- [Meshy↗](https://www.meshy.ai)

  AI image-to-3D for characters, creatures and organic props that parts can't build.

- [Blender↗](https://www.blender.org)

  Modelling, fixing AI meshes, rigging and exporting GLB for Roblox.

- [Sketchfab↗](https://sketchfab.com)

  A huge model library. Check each model's licence before using it.

- [Poly Pizza↗](https://poly.pizza)

  Free low-poly models that suit stylised Roblox games.

### UI

- [Photopea↗](https://www.photopea.com)

  A free Photoshop-style editor in the browser, for cutting and editing UI art.

- [Figma↗](https://www.figma.com)

  Designing screens and layouts before building them for Roblox.

- [Vector Icon Pack Pro↗](https://rhosgfx.itch.io)

  A paid icon pack by RhosGFX. Pick one pack per game and stick to it.

### AI + Studio

- [Claude Code↗](https://claude.com/product/claude-code)

  The AI coding assistant the build prompts on this site are written for.

- [Roblox Studio MCP server↗](https://github.com/Roblox/studio-rust-mcp-server)

  Roblox's official bridge that lets an AI assistant run Luau, insert assets and read Studio.

### Scripting

- [Lune↗](https://github.com/lune-org/lune)

  Run Luau outside Studio: build scripts, generators and economy simulations.

- [Jest Lua↗](https://github.com/jsdotlua/jest-lua)

  Unit tests for Luau, Jest-style.

- [Roblox Creator Hub docs↗](https://create.roblox.com/docs)

  The engine reference. Check it before trusting any API from memory, including an AI's.

### Video & music

- [ffmpeg↗](https://ffmpeg.org)

  Trailer editing from the command line: cuts, speed ramps, crossfades and loudness.

- [ACE-Step↗](https://github.com/ace-step/ACE-Step)

  Open-source AI music you can run on your own machine, for loopable game tracks.

## Stud-style build references

142 builds grouped by what they teach. Study them for palette (high-key pastel greens, coral and terracotta earth, candy-coloured accents), for how maps read as one island from above, and for the detail vocabulary: striped awning stalls, stepped roofs, arched bridges, chunky trees. Pair them with the [[Stud-style surfaces that look intentional|building guides]].

Builds by Roblox creators, shared on X. Images load from their original posts and open full size when clicked.
