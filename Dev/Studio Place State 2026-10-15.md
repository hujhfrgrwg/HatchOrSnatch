# Studio place state: 15 Oct 2026

Read-only audit of **Evolve or Steal Prototype** (place 92934789398619, universe/game 10770957265), done through the Studio MCP. Nothing in Studio was changed. Compare with [[Evolve or Steal GDD v0.4 Summary]].

The code calls itself `GameConfig.VERSION = "0.4.0"` and says it was built against GDD v0.4. Many config comments carry "developer, Oct 15" tuning notes, and a teammate did a movement/animation reference pass.

## Architecture
- **Server boot:** `ServerScriptService.EOS.Bootstrap` creates the remotes (`Shared/Net`) and then starts the services in this order: Character → Map → Npc → NpcSkin → Data → Match → Player → Economy → Ability → Lobby → Practice → Sandbox (Studio only), then `MatchService.start()`.
- **Pure logic, testable:** `Core/MatchLogic` (match rules engine, no yields) and `Core/ProfileLogic` (profile transforms, migrations, exact-once ledgers). Also `Core/RateLimiter`, with per-remote limits in `GameConfig.RateLimits`.
- **Services:** Match (authoritative loop and state attributes on `ReplicatedStorage.EOS_State`), Data (DataStore `EOS_Profiles_v2` with session locks, autosave and retries; Studio is memory-only unless the workspace attribute `UseDataStore` = true), Economy (hatch, equip, shop, cosmetics), Ability (Decoy/Scout/Brake), Npc and NpcSkin (bots that look like your friends), Map (arena rotation), Lobby, Player (AFK, volunteer, quests), Practice (low-population bot, never rewarded), Analytics, Character.
- **Shared config:** `GameConfig` (timing, match, capture, movement, dash, stab, camera, NPC, feature flags, data, rate limits), `EconomyConfig` (GDD v0.4 economy), `TierConfig`, `QuestConfig`, `RewardConfig` (legacy Shells), `AnimConfig`, `Layout`, `EggModel`, `PetModel` (voxel pets built from Parts), `Ragdoll`, `Format`. UI: `EOS/UI/Theme`, `UIKit`.
- **Client:** `StarterPlayerScripts.EOS.ClientMain` loads the controllers: UIController (~1,700 lines), Movement (custom momentum and dash), CharacterAnim, CameraFX, Tag, Pets, NpcSkins, SlideFX, WorldFX, Outlines, FacePlayer, Fit, Sound.
- **UI:** built ahead of time into StarterGui as `EOS_HUD` (quests/incubator pills, stats/settings, a left rail with Shop/Pets/AFK/Hunt toggle, match bar, wallet, ability bar, dash/tag buttons for touch, feed, banner, toasts), `EOS_Menus` (Quests, Incubator, Pets, Shop, Stats, Settings), `EOS_Results` (podium, thief, your breakdown) and `EOS_Overlay`. They're generated by `ServerStorage.EOSBuild.UIBuilder`.
- **World:** `require(game.ServerStorage.EOSBuild.BuildAll)()` rebuilds `Workspace.EOS_World` (Lobby + Arena + Sea) in edit mode. The lobby has a spawn, statue plaza, spectator terrace, leaderboards, event board, treasure chest, shop stall, incubator and decor. Arena maps are Hatchery Farm, Sunny Cove and Frosty Pass (`EOSBuild/Maps`). All three share one shape and only the field length differs. Inactive maps wait in `ServerStorage.EOS_Maps`, and `MapService` rotates them between matches. Studio attribute `EOS_FixedMap` pins one.
- **Tests:** `ServerStorage.EOSBuild.LogicTests` (a "TEST_PLAN" covering A01–A24 and B01–B14) and `DataTests` (B07 plus session locks, against a mock store). They run from the command bar. The TEST_PLAN document itself isn't in this repo.

## Movement and combat feel (all in `GameConfig`)
- Speed 28 for both roles (lobby 26). **No jumping**: Space dashes instead (58 studs/s burst, 2 s cooldown, side/back only, no forward dash). **Catchers can't dash.**
- Backpedalling at 18 keeps the player facing the camera. Momentum values come from a Huss Valley reference clip. Live tuning goes through attributes on `ReplicatedStorage.EOS_Tuning`.
- The Catcher hit is a full-body knife lunge stab. The hit is decided on the click (6.5-stud reach, 1.0 s cooldown) and followed by a 0.7 s slow at 55% speed.
- Over-the-shoulder camera and mouse lock in matches. The head follows the camera.

## Loose ends and risks
1. **Match-length rule differs from the GDD.** The clean-streak ending can produce long matches. Pick one rule and record it.
2. **Tier names clash with material names.** Egg tiers are "Basic / Uncommon / Rare / Epic" (`TierConfig`), but materials are "Common / Rare / Epic". So an "Uncommon" L2 egg pays a *Rare* piece, and a "Rare" L3 egg pays an *Epic* piece. That will confuse players.
3. **Legacy Shells are still in the code.** `RewardConfig` and `MatchLogic` still compute Shells (the `RunnerEvolved` event sends them). `QuestConfig` rewards are commented as "Shells" and should be checked: do quest rewards pay Gold now? ProfileLogic migrates old Shells into Gold.
4. **No receipt handler.** One is needed before Gem packs go on.
5. **`FWP_PetLibrary` and `Workspace.FWP_PetShowroom`** are a pet library and showroom copied from Fishing with Pets (HOOKED). The launch pets use the voxel `PetModel` instead. Decide whether the FWP assets stay in this place.
6. **Workspace has dev scaffolding:** `35+ General Movement Animations Pack`, `EOS_AnimPicker`, `EOS_DaggerPicker`, `knife attack anim`, several sword/knife meshes (Murasama, Musou No Hitotachi, …), the `dagger throw` KeyframeSequence and `_MapPreview`. ServerStorage holds dated backups (`_Backup_*`, `R6Reference*`, `EOS_AnimBackup`, `MovementComparisonCandidates`). Clean these up before publishing.
7. **The game is named Evolve or Steal**, but this repo, its notes and the ticket prefix (`HOS-`) still say Hatch or Snatch.
8. **The edit-mode HUD is visible in StarterGui**, as the 15 Oct screenshot shows. That's normal for a pre-built UI and just worth knowing.
