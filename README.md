# Hatch or Snatch

A Roblox game. Agent notes start at [`Hatch or Snatch Home.md`](Hatch%20or%20Snatch%20Home.md); rules for Claude sessions are in [`CLAUDE.md`](CLAUDE.md).

- `.claude/skills/`: Claude skills (RoClicks Roblox skills, claude-music, agent-browser, scrapling, jest-lua, graphify, humanizer).
- `.mcp.json`: Roblox Studio MCP connection (needs `ROBLOX_MCP_TOKEN`).
- `tools/mcp/start_mcp_server.ps1`: runs the MCP server on Hunter's PC.
- `tools/upload/upload_assets.py`: Open Cloud uploads for sounds, images and models.
